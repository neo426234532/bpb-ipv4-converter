Converted JSON

What this converter changes:

• Changes proxy sockopt.domainStrategy to UseIPv4.
• Changes routing domainStrategy to UseIPv4.
• Changes direct outbound domainStrategy from UseIP to UseIPv4.

IPv6 addresses already present in dns.hosts or IP routing lists are not deleted.
